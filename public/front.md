# Frontend — `public`

Esta pasta contém o frontend do Dashboard CNC V1.1.

## Responsabilidade

O frontend será responsável pela interface utilizada para visualizar informações e interagir com a CNC.

## Diretrizes

- Os arquivos entregues ao navegador deverão permanecer dentro de `public/`.
- A estrutura de componentes ainda será definida.
- A estrutura de estilos ainda será definida.
- A organização do JavaScript do frontend será definida gradualmente conforme as necessidades da interface.
- Novas pastas e arquivos devem ser criados somente quando houver uma responsabilidade claramente definida.

## Estado atual

A estrutura interna do frontend ainda não foi definida.

As decisões de arquitetura serão documentadas à medida que forem implementadas.
