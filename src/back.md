# Backend — `src`

Esta pasta contém o backend do Dashboard CNC V1.1.

## Responsabilidade

O backend será responsável pela lógica executada no servidor e pela comunicação entre o Dashboard e os recursos da CNC.

## Diretrizes

- O ponto de entrada da aplicação será `src/app.js`.
- Código exclusivo do backend deverá permanecer dentro de `src/`.
- A estrutura interna desta pasta será definida gradualmente conforme o projeto evoluir.
- Novas pastas e módulos devem ser criados somente quando houver uma responsabilidade claramente definida.

## Estado atual

A estrutura interna do backend ainda não foi definida.

As decisões de arquitetura serão documentadas à medida que forem implementadas.
